# Anna George — Personal Portfolio

A responsive student developer portfolio created for a Web Technology assignment using only vanilla HTML5, CSS3 and JavaScript.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- DOM manipulation
- localStorage

## Features

- Semantic HTML5 structure
- Responsive desktop/tablet/mobile layout
- Sticky navigation
- Mobile hamburger navigation
- Dark/light theme toggle
- Theme persistence using localStorage
- Dynamic project cards from a JavaScript array
- Project category filtering
- Contact form validation using JavaScript regular expressions
- Inline error messages and success message
- Scroll-to-top button
- Downloadable resume
- GitHub and LinkedIn links

## Before Publishing

Replace these placeholders in `index.html` and `js/script.js`:

- `[YOUR EMAIL]`
- `[YOUR PHONE]`
- `[YOUR GITHUB URL]`
- `[YOUR LINKEDIN URL]`

Add:

- `images/profile.jpg`
- `images/project1.jpg`
- `images/project2.jpg`
- `images/project3.jpg`
- `assets/resume.pdf`

Only replace project links with real repositories or demos. Do not invent repository URLs.

## Run Locally

Open `index.html` directly in a browser. No framework, package manager or build process is required.

## GitHub Pages

1. Create a public GitHub repository named `portfolio`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Click **Save**.
7. GitHub will publish the site at:

`https://YOUR-USERNAME.github.io/portfolio/`

The exact URL depends on the GitHub username and repository name.
